# Creating skills

Carpeta `skills/<name>/SKILL.md`. `name` en frontmatter = nombre del folder.

`description` en tercera persona, con qué hace y cuándo usarla.

Usar `disable-model-invocation: true` solo para acciones humanas.

Meter detalle en `references/` o `templates/`. Mantener `SKILL.md` corto.

No agregar MCP ni skills de un framework específico en este plugin base.
