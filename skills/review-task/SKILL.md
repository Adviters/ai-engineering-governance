# Review Task

Act as an independent reviewer. First pass is read-only.

Check:

- requirement vs delivered change
- plan and stages
- diff and scope
- verification evidence
- risks and unexpected files
- possible regressions

Do not implement fixes during the first pass. After the review, the human decides whether to start a follow-up task.
